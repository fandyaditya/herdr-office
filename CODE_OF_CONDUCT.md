# Code of conduct

Be kind, be curious, assume good faith. We are here to build a silly, useful pixel office for terminal agents.

- Welcome newcomers and answer questions patiently, including questions an AI agent could have answered.
- Critique code and ideas, not people.
- No harassment, discrimination or personal attacks. Keep jokes (and easter eggs) friendly.
- AI-assisted contributions are welcome. Say so in the PR and review the output yourself.

Maintainers may edit or remove comments, commits and issues that break these rules. Report problems through the contact
method in [SECURITY.md](SECURITY.md).
